
# Project Statement: Student Performance Management System

## 1. Problem Statement
Managing student records and calculating academic performance
manually can be time-consuming and may lead to errors.
Teachers need a simple system to maintain student details,
marks and grades and to analyse overall performance.

This project develops a Python-based Student Performance
Management System to simplify these tasks.

## 2. Project Scope
The system supports basic student record management and
academic performance analysis. It allows users to add, view,
search, update and delete records. It also calculates grades
and generates a performance report.

## 3. Target Users
- Teachers
- School and college administrators
- Users who need to manage student academic records

## 4. High-Level Features
- Add student details
- View all student records
- Search students by roll number
- Update student details and marks
- Delete student records
- Calculate grades
- Generate performance reports
- Validate user input
- Store records in a text file

## 5. Objectives
- Simplify student record management.
- Reduce manual calculation.
- Provide quick access to student records.
- Analyse average, highest and lowest marks.
- Identify pass and fail counts.

## 6. Technologies
- Python 3
- File handling
- CSV module
- Functions and modules
- Visual Studio Code

## 7. Limitations
- The application currently uses a command-line interface.
- It uses a local text file for data storage.
- It does not include user login or multiple-user access.
